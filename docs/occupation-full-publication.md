# Full occupation publication

> These bundles are now history: the reviewed inventory is `Resources/Essenthos/person-occupations.json`, loaded by the `occupations` step (docs/occupation-publication.md). The SHA-pinned `occupations <bundle> <sha256>` verb and the `occupation-preview` verb no longer exist.

`scripts/publish_person_occupations.py` prepares source-bound review packets from the completed occupation reading, validates explicit role and person-context decisions, and compiles the admitted publication. It makes no model requests or database calls. Use the registered `occupation-full-review` action; `occupation-full-check` runs the offline guards.

The first immutable review directory is `Resources/Essenthos/generation/occupation-full-publication-2026-10-27-v1`. Its `manifest.json` binds the copied result, person catalogue and every original source packet. `groups.json` retains 1,281 person/category/raw-role groups and 2,040 positive contexts. `taxonomy.json` maps every one of the 308 category/key combinations to a canonical four-language concept or an explicit hold. `decisions/part-a.json` and `part-b.json` contain a source disposition for every group, with selected context identifiers. A model's earlier acceptance is not a source-review decision.

`terminal-review.json` independently closes four facts held by the original checker's Cyrillic/Hebrew character error. The correct original draft and full source are retained, and no paid raw output/checkpoint is changed. `source-adjudications.json` records a lead source reading that splits Jotham's household administration and judging into separate supported offices. These are explicit source decisions rather than parser repairs presented as model decisions.

`observation-dispositions.json` preserves all 6,169 observations. The 4,621 original nonoccupation observations are not promoted; the 1,548 unconfirmed observations remain explicitly held. This policy is not a claim that every observation is false. Moral labels, kinship/status, one-off actions, metaphor and unresolved identity do not acquire an occupation by normalization. Empty original results likewise are not negative vocation assertions.

Compilation refuses incomplete/duplicate review inventories, wrong manifest hashes, missing source contexts, placeholder taxonomy decisions and incomplete gendered language labels. Exact NFC quotations and original printed/canonical placements remain separate. The compiler retains all 16 previously admitted person-role pairs. Unselected repetitions stay in the frozen source inventory; only the source contexts explicitly selected by a reviewer are published.

`reviewed-source-manifest.json` pins review files, component licences and the previous admitted bundle. The source compiler hash uses UTF-8/LF program text so Git's line endings do not change a replay; scripture evidence uses only NFC, never source-code newline normalization. The frozen review receipt makes identical inputs compile identical bundle bytes. The final bundle keeps publication ID `person-occupations-reviewed-2026-10-27-v1`, so the loader atomically replaces that publication while preserving any other publications. `publication-summary.json` records distinct pairs and the expected SHA256.
