# Nestle1904.xml, berean-interlinear-glosses.xml

**Nestle 1904 Greek New Testament**, from **biblicalhumanities.org**,
<https://github.com/biblicalhumanities/Nestle1904>.

The 1904 edition is out of copyright. The transcription, the morphology and the Strong
numbers are the modern work, and biblicalhumanities.org released them into the public
domain — stated in the morphology readme of that repository, read on **2026-08-31**. The
corpus records the text as `CC0-1.0` and names no rights holder, because there is none to
name.

## Neither file carries a statement of its own

`Nestle1904.xml` opens straight into `<text><w …>` and the glosses file into
`<root><verse …>`. There is no header, no OSIS work element, no comment — checked on
2026-09-03. **The only licence statement for this data is upstream**, which is precisely
what this file exists to compensate for: the reading was done once, on a date, against a
named repository, and would otherwise survive only in a code comment in
`Loading/NestleTextSource.cs`.

Anyone re-checking should read the readme in that repository rather than the GitHub
licence badge — for the neighbouring `etcbc` folder those two disagree, and a badge is
not a licence statement.

## berean-interlinear-glosses.xml

English glosses keyed to the same `osisId` word identifiers, from the Berean interlinear.
The Berean Standard Bible is public domain by its publisher's own licensing page —
`../Berean/LICENCE.md` records that statement verbatim, along with the site footer that
contradicts it.

## Why it is attributed anyway

Public domain removes the obligation, not the reason. RUL-0181.
