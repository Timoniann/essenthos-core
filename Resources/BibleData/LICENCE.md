# BibleData, the 2024 JSON release — not loaded

Six JSON files, 13.2 MB, from Brady Stephenson's BibleData before it was republished as CSV.
**Nothing in this project reads them.** The encyclopedia loads `../BibleData2026`, whose licence
note beside it records all four statements found in that release and which of them governs.

They are kept because they are the only copy on this machine of what the dataset looked like in
2024, and because deleting data that has no fetch script is how a corpus quietly stops being
reproducible — thirteen of the twenty folders here are in that position.
